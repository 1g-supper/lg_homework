# 林广 · 个人作品集

一个基于原生前端技术构建的个人作品集网站，以樱花、武士刀与神社为主题视觉元素，用于展示个人介绍、项目作品、技能与联系方式。

## 功能

- **个人简介**：首页 Hero 区域展示自我介绍与关注方向
- **作品集展示**：数据驱动的项目卡片列表（轻记账、拾光集市、城市脉搏、课语通），支持点击展开动画
- **技能标签**：动态渲染个人技能标签
- **关于我 / 联系我**：个人介绍与联系方式展示
- **主题切换**：浅色 / 深色主题切换，记忆用户选择（localStorage）；另有樱花 / 武士 / 神社三种隐藏主题彩蛋
- **移动端适配**：桌面端侧边栏布局，移动端汉堡菜单抽屉导航
- **视觉动效**：樱花花瓣飘落、明神门装饰、自定义光标、滚动渐显等
- **可访问性**：支持 `prefers-reduced-motion` 关闭动效；无 JS 时内容仍完整可见

## 技术栈

- 原生 HTML、CSS、JavaScript（无框架、无第三方 UI 组件库）
- CSS 分层组织：`base.css`、`layout.css`、`components.css`
- 项目数据独立存放于 `assets/data/projects.js`，新增项目只需在数组中追加一条记录

## 目录结构

```
lab4/
├── index.html              # 页面结构
├── css/
│   ├── base.css            # 基础样式与变量
│   ├── layout.css          # 布局样式
│   └── components.css      # 组件样式
├── js/
│   ├── theme-init.js       # 主题预加载（避免闪烁）
│   └── main.js             # 页面交互逻辑
├── assets/
│   ├── data/projects.js    # 项目数据
│   └── images/             # 项目示意图（SVG）
└── .vscode/
```

## 运行方式

无需构建，直接通过浏览器打开 `index.html`，或使用任意静态服务器启动：

```bash
# 例如使用 Python 启动本地静态服务
python -m http.server 8000
```

然后访问 `http://localhost:8000`。
